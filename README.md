# 🎨 Pure HTML & CSS Projects

A collection of clean, minimal, and responsive UI components built with **pure HTML and CSS** — no frameworks, no libraries, just vanilla web technologies.

---

## 📖 About

This repository contains multiple small-scale frontend projects that I've built to practice and showcase my HTML & CSS skills. Each project is:


- ✅ Cross-browser compatible
- ✅ Built with semantic HTML5
- ✅ Styled with modern CSS3
- ✅ Completely framework-free

---

## 🛠️ Technologies Used

- **HTML5** — Semantic markup
- **CSS3** — Flexbox, CSS Grid, Custom Properties, Animations & Transitions
- **Google Fonts** (optional)
- **Font Awesome** (optional, for icons)

No JavaScript, no frameworks, no build tools — just pure frontend goodness.
